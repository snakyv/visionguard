# Datasets

`demo/` is a bundled synthetic YOLO-format dataset used for smoke testing, pipeline validation and reproducible examples. It contains `person`, `forklift` and `car` classes plus a generated video.

The synthetic dataset is intentionally small and must not be presented as evidence of real-world model accuracy. For portfolio training results, replace or extend it with a legally usable, manually reviewed real-world dataset and document the labeling policy, train/validation split and error analysis.
